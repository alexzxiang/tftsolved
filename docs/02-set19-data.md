# 02 — Set 19 "Prismatic Tour" Data

Snapshot 2026-11-16 from PBE-derived listings. Everything here is **[pbe]** unless marked. Riot states content may change before release.

## Set at a glance

- 94 champions: 15 one-cost, 18 two-cost, 16 three-cost, 22 four-cost, 19 five-cost, 4 seven-cost. No 6-costs.
- 47 traits: 14 multi-member bands, a set of classes, and many single-champion "solo artist" traits.
- **36 unlockables**: 1 one-cost, 7 two-cost, 4 three-cost, 9 four-cost, 11 five-cost, all 4 seven-costs.
- Riot groups unlocks into three roles **[confirmed]**:
  - **Flex**: fit several comps, can be added at various points (example: Vayne).
  - **Capstone**: mostly 5-costs that finish a deep vertical.
  - **Chase**: hard challenges worth pursuing only when things line up.
- Live: patch 19.1 on 2026-12-01; 19.2 on 2026-12-15.

## Structural observations

These drive engine design more than any single number.

1. **Gu Feng is this set's gated chase trait.** Wukong, Janna and Lee Sin all require fielding Xayah, a base 4-cost. No Xayah, no Gu Feng. Xayah's availability (4-cost odds, contest) is a first-class input. Three different counters run on her: team damage, interest earned, player damage.
2. **Hyperpop is a self-unlocking vertical.** Only Ziggs is in the base shop. Kobuko needs a starred, itemised Ziggs; Lulu and Tristana need Hyperpop active and combat counters; Teemo needs 900 Hype. The whole trait is a chain starting from a 1-cost, so it must start early.
3. **Dependency chains exist.** Aphelios needs Alune or Yone starred; Alune is an unlock. Kobuko→Ziggs, Tibbers→Annie, Baron→Malzahar. The unlock set is a graph, not a list.
4. **Mutual exclusion exists.** Unlocking one Akali permanently blocks the other. The engine must warn before an irreversible unlock that kills a better plan.
5. **Many conditions are combat-stat accumulators** (casts, kills, damage, Captivated seconds, cheers, inspires). These cannot be computed from the board. Progress must be read from the UI and rates estimated from recent rounds.
6. **Two economy conditions cut against normal play.** Janna rewards holding interest with Xayah fielded; Pyke rewards holding gold at level 7+. Both conflict with rolling down, so their cost is tempo, not gold.
7. **Streak condition interacts with a trait.** Rakan wants a win or loss streak at level 8+; True Damage A/B-Side pays for the same streaks.
8. **Positional conditions** (Vladimir, Taliyah) are cheap to satisfy for one combat if the engine reminds you, but cost a fight if done carelessly.
9. **Level gates cluster at 7.** Nine of the 4- and 5-cost unlocks require level 7, so the level-7 timing is the main mid-game unlock checkpoint.
10. **Cheap item unlocks are near-free.** Ashe, Nasus, Renata, Samira, Jinx only need items on a trait member. These are the "fits your board, take it" alerts.
