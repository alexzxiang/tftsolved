Privacy

TFTSolved collects as little as it can. This page says exactly what that is. Last updated November 23, 2026.

This website

The site is a set of static pages. It sets no cookies, runs no analytics or advertising, has no accounts and no forms, and asks you for nothing. Its host, Vercel, processes standard request logs (such as IP address and browser) to serve and protect the site. The font loads from Google Fonts, so Google receives your IP address when your browser fetches it.

Riot Games data

TFTSolved uses the Riot Games API to read public ranked Teamfight Tactics match results and turn them into aggregate statistics about team compositions: average placement, top-four rate, common boards and items. Player identifiers are used only to find matches. They are not stored with the board records TFTSolved keeps, and no individual player is shown, searchable or profiled.

Signing in

There are no accounts today. If a post-game review that uses Riot Sign On is added later, this page will be updated before it launches to say exactly what it reads and keeps.
